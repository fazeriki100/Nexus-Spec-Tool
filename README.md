\# 🖥️ Nexus System Spec Tool (GUI)



A modern, lightweight hardware diagnostic utility featuring a clean \*\*Graphical User Interface (GUI)\*\*. \*\*Nexus System Spec Tool\*\* allows you to instantly scan and display your computer's core hardware specifications with a single click, completely eliminating the need for complex command-line tools.



\---



\## ✨ Features



\* \*\*Real Graphical Interface:\*\* Built as a standalone Windows application with buttons and a dedicated output window.

\* \*\*Processor / CPU Scan:\*\* Instantly retrieves the exact model and name of your installed processor.

\* \*\*Motherboard Identification:\*\* Detects the manufacturer and product model of your motherboard (details often hidden in standard menus).

\* \*\*100% Native \& Safe:\*\* Built using standard Microsoft HTA (HTML Application) technology. It requires zero external installers or heavy frameworks.



\---



\## 🚀 How to Run It



1\. \*\*Download\*\* the `nexus-spec.hta` file from this repository.

2\. Double-click the `nexus-spec.hta` file to launch the application window.

3\. Click the blue \*\*"SCAN SYSTEM"\*\* button and wait a second for your hardware layout to appear in the dashboard.



\---



\## 🔒 Security \& Code Transparency



\* \*\*Safe \& Sandboxed:\*\* This utility only performs passive hardware inquiries (`wmic`). It does not modify system settings, registries, or user files.

\* \*\*Open Source Framework:\*\* Since it uses HTML and VBScript, you can audit the entire source code anytime by simply right-clicking the file and selecting "Open with Notepad".
